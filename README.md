# Particle System Demo

A demonstration of how to create and configure particle systems using the Phaser game framework.

*Basic Emitter:* frequency, lifespan, quantity, speed, along with starting and stopping.

*Visual:* color cycling, alpha, scale, rotation, and blend mode.

*Physics:* velocity, gravity, bounds.

*Emit & Death Zones:* edge zones (particles spawn along a shape's boundary), random zones (particles spawn within a shape), and death zones (particles are killed when they enter a region).

*Showcase:* a scene that demonstrates multiple particle systems interacting to create a "Cosmic Portal".

See PARTICLE_GUIDE.md for an overview of using Phaser particles.
